# PickTESH ???

Plataforma PWA de pedidos Pickup para la cafetería del TESH con pagos seguros en la red Stellar y penalizaciones automáticas mediante Smart Contracts (Soroban).

## Estructura del Proyecto

- frontend/: Aplicación PWA construida en React + Vite.
- backend/: API REST en Node.js para gestión del menú, ordenes y eventos.
- contracts/: Smart Contracts en Rust (Soroban) para custodia de fondos y penalizaciones.
